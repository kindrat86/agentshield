The Challenge

AgentShield's rules engine processes 74 test scenarios across 12 categories covering 10 rule types. All 74 pass. But no test suite is perfect.

Find a transaction that the engine handles incorrectly, and I'll pay you $1,000.

What Counts as a "Break"

  • False negative, a transaction that SHOULD be blocked but passes through
  • False positive, a legitimate transaction that gets wrongly blocked
  • Precision bug, Decimal arithmetic edge case producing wrong amounts
  • Rule priority conflict, two rules matching the same transaction with contradictory actions
  • Velocity race condition, concurrent transactions evading the velocity counter
  • Session budget miscalculation, decay tightening producing incorrect thresholds

How to Submit

Reproduce the issue using the eval gym framework:

pip install agentshield # Write a failing test case python3 -c " from agentshield import SpendControlEngine from decimal import Decimal engine = SpendControlEngine() # ... your reproduction code ... # Show expected vs actual result "

Submit your reproduction to: GitHub Issues with the label bounty.

The Rules

  • First person to report each unique bug wins
  • Bug must be reproducible using the published eval gym
  • Payout via PayPal or GitHub Sponsors within 7 days of confirmation
  • Max $1,000 per bug. Max 5 bounties total ($5,000 max payout).
  • Decision of the maintainer (Maryan K.) is final
  • Bounty runs until December 31, 2026 or 5 valid bugs found

Why a Bounty?

Because the best way to prove correctness is to invite people to break it. If nobody can find a bug in 4 months, that's stronger proof than any test suite.

And if someone DOES find a bug, great. We fix it, the reporter gets $1,000, and the engine gets stronger.
